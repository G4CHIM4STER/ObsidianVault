## Память

При выводе команды:

```sh
free -h
```

Получаем следующий набор значений:

|      | total | used  | free  | shared | buff/cache | available |
| ---- | ----- | ----- | ----- | ------ | ---------- | --------- |
| MEM  | 14Gi  | 12Gi  | 507Mi | 479Mi  | 2,7Gi      | 2,4Gi     |
| Swap | 8,8G  | 2,2Gi | 6,6Gi |        |            |           |

- **total** - общий доступный объем **физ. памяти** системы
- **used** - сколько памяти занято исполняемыми программами (процессами)
- **free**
- **shared**
- **buff/cache**
- **available**

### Цель управления памятью

Основная цель управления памятью в Linux - **предоставление процессам "иллюзии" непрерывного адресного пространства**, изолированного друг от друга при эффективном использовании физическое память

## Физическая память

**Физическая память** - это наша RAM, доступная системе.
Управляется она при помощи **менеджера физической памяти**, который отслеживает какие участки памяти заняты, а какие свободны

### Основные единицы

- **Страница (page)**: базовая единица управления памятью. Обычно 4КБ (может быть больше — hugepages).
- Страницы могут быть:
    - **активные / inactive**
    - **анонимные** (без привязки к файлу)
    - **file-backed** (взяты из mmap или из файловой системы)

## Виртуальная память

Общая идея - **каждому процессу выдать собственно виртуальное пространство, которое:**
- Мапится на физическую память (RAM)
- Может быть частично выгружено на диск (swap),
- Изолировано от других процессов.
По сути - виртуальноая память это ссылка либо на конкретную память в RAM, либо на SAWP.

> [!question] Каким образом реализуется изоляция ?

Виртуальная память — это **абстракция**, которая делает возможным:
- Мультизадачность,
- Защиту памяти,
- Упрощение загрузки и использования программ.

## Структура виртуального адресного пространства

Процесс в Linux (на x86_64) получает 128 ТБ адресного пространства (по умолчанию), но используется только часть:

|Область|Назначение|
|---|---|
|Text segment|Код программы|
|Data segment|Статические переменные|
|Heap|Динамически выделяемая память (malloc, new)|
|Stack|Локальные переменные и вызовы функций|
|Memory-mapped|Маппинг библиотек и файлов|
