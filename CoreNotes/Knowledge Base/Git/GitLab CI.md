## Общая информация

### Основные компоненты GitLab CI/CD:

1. **`.gitlab-ci.yml`**  
    Конфигурационный файл в корне репозитория. Описывает этапы (stages), задания (jobs), образы (Docker/Runner), переменные и триггеры.
    
2. **Jobs (задания)**  
    Это отдельные единицы работы (например, `build`, `test`, `deploy`), которые выполняются на runner'е.
    
3. **Stages (этапы)**  
    Группируют задания по порядку выполнения (например: `build -> test -> deploy`). Jobs внутри одного stage могут выполняться параллельно.
    
4. **GitLab Runners**  
    Агент (локальный или в облаке), который выполняет jobs. Это может быть Docker Runner, Shell Runner, Kubernetes Runner и т.д.
    
5. **Переменные окружения (CI/CD Variables)**  
    Используются для хранения секретов, токенов, параметров окружений.
    
6. **Artifacts и Caches**
    
    - **Artifacts** — артефакты, сохраняемые между этапами (например, бинарники или отчёты).
        
    - **Cache** — кеш для ускорения, например, чтобы не качать библиотеки заново.

## Инсталляция

### Установка раннера на систему

Тут все просто:
1. Вот [ссылка](https://docs.gitlab.com/runner/install/linux-repository/)
2. Либо можно просто добавить репозиторий и скачать соответствующий пакет:

```sh
curl -L "https://packages.gitlab.com/install/repositories/runner/gitlab-runner/script.deb.sh" | sudo bash

sudo apt install gitlab-runner
```

### Регистрация раннера непосредственно в самом GitLab

1. Заходим/создаем проект в самом **GitLab**. 
2. Переходи в **Setting** -> **CI/CD** -> **Runners** -> **New project runner**
3. Выполняем все согласно инструкциям
