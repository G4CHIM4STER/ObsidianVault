```mermaid

sequenceDiagram

participant User as Пользователь

participant WebUI as Веб-интерфейс (NocoDB)

participant DB as База данных

participant Cron as Cron-скрипт

participant Notif as Функция уведомлений

  

User->>WebUI: Ввод данных об отпуске

WebUI->>DB: Сохранение информации об отпуске

note over DB: Запись сохраняется, триггеры/функции могут выполняться

Cron->>DB: Запрос данных для отпусков (за 14 дней до события)

DB-->>Cron: Возвращает соответствующие записи

Cron->>Notif: Инициирует отправку уведомления

Notif-->>User: Отправка сообщения о предстоящем отпуске

```
