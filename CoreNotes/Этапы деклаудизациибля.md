## Proxmox
1. назначаем для **ВСЕХ** тачек статический айпишник, потому что иначе потеряется доступ к тачке (VNC при переходе на архитектуру q35 ломается) очень поможет вот такой формат:
```yaml
network:
  version: 2
  ethernets:
    lan:
      match:
        macaddress: BC:24:11:FB:31:8F
      set-name: lan0
      dhcp4: false
      addresses:
        - 172.19.133.153/24
      routes:
        - to: default
          via: 172.19.133.1
```
где *macaddress* - мак сетевого устройства.
2. для проброса GPU следуем этому гайду: https://bafista.ru/probros-pci-ustrojstv-v-proxmox/ (опцию **Rom Bar** можно не включать, иногда с ней есть проблемы)
